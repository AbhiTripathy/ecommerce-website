# Cara Fashion Hub

This is an E-commerce website for a fashion brand.

## Features
- Login, Registration, and Authentication

## Tech Stack
- React
- Vite
- Tailwind CSS

## Getting Started

Clone the repository:

    git clone 

Install dependencies:

    npm i

Start the development server:

    npm run dev
